# Устранение проблемы с переменными в Railway

## Проблема
Переменные `Telegram__BotToken` и `Telegram__BotSecretKey` есть в Railway, но приложение их не видит (length: 0).

## Решение

### Шаг 1: Проверьте значение переменной

1. Откройте Railway Dashboard → ваш проект → сервис с бэкендом
2. Перейдите в **Variables**
3. Найдите `Telegram__BotToken`
4. Нажмите на три точки (⋮) → **Edit**
5. **Убедитесь, что значение НЕ пустое!**
   - Должно быть: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz` (ваш Bot Token)
   - НЕ должно быть пустым или пробелами

### Шаг 2: Убедитесь, что переменная применена к сервису

Если переменная помечена как **"Shared Variable"**, она может быть не применена к вашему сервису:

1. В разделе **Variables** найдите `Telegram__BotToken`
2. Если видите иконку "Shared Variable" (график с несколькими сервисами):
   - Нажмите на три точки (⋮) → **Edit**
   - Убедитесь, что переменная применена к вашему сервису
   - Или создайте переменную напрямую в сервисе (не как shared)

### Шаг 3: Создайте переменную напрямую в сервисе (рекомендуется)

1. Railway Dashboard → ваш проект → **сервис с бэкендом** (не проект, а именно сервис!)
2. Перейдите в **Variables** (внутри сервиса)
3. Нажмите **"+ New Variable"**
4. Добавьте:
   - **Key**: `Telegram__BotToken` (двойное подчеркивание)
   - **Value**: `<ваш_bot_token>` (из @BotFather)
5. Сохраните

### Шаг 4: Перезапустите сервис

1. Railway Dashboard → **Deployments**
2. Нажмите **Redeploy** или подождите автоматического перезапуска
3. Подождите 1-2 минуты

### Шаг 5: Проверьте логи

После перезапуска в логах должно быть:
```
BotToken config check - Telegram:BotToken: True (length: XX), Telegram:BotSecretKey: ...
HasBotToken: True
Using HASH validation (bot token)
HASH validation result: True
```

## Где взять Bot Token

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/mybots`
3. Выберите вашего бота (`@travelrustikbot`)
4. Выберите **"API Token"**
5. Скопируйте токен (формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Важно

- ✅ Переменная должна быть создана **внутри сервиса**, а не только как Shared Variable
- ✅ Значение не должно быть пустым
- ✅ Имя должно быть `Telegram__BotToken` (двойное подчеркивание)
- ✅ После изменения переменных нужен перезапуск сервиса
